# FontCrafter
font editor and TrueType debugger

Small, Reliable, Elegant.
Efficiently create font with your perfect curves.

FontCrafter, a small dedicated vector font editor, also a color font editor, a high performance font compiler, and a TrueType instruct debugger, a small artistic font suite on Mac. The app provides functions to validate and inspect TrueType and OpenType vector font and color font, scan and detect every table in a font has issues or not, detect glyph indexes in font binary has issues or not, and detect any other possible font format issues to ensure font binary completely match specification of TrueType and OpenType. Verify a glyph has correct shape or not under different ppem, verify properties of each layer of a color glyph is correct or not, such as opacity, blend mode, fill type, fill color and gradients. Verify an OpenType feature is active or not, verify arbitrary combination of OpenType features correctly rendered or not by leveraging the power of FreeType and Harfbuzz, such as validate shape, position and joint points of ligature and marks. User can conveniently append missing characters by importing SVG files, editing shape of normal vector glyphs by conveniently outline points dragging operation and align shapes to match design metrics, editing shape and color settings for each layer of color glyphs, compile vector and color/emoji mixed font, compile composite glyphs using precise layout settings of components, generate high quality TrueType instructs for glyphs with the embedded auto-hinting engine, compile small color/emoji mixed font for Web browser, compile icon/color font for game development, etc. Supports all color font format including ColrV0 and ColrV1 layout and SVG color font, sbix and Google color font format.

The app has an intuitive and concise user interface and industrial strength TrueType compiler to support font creating, editing and compilation, log low-level diagnostic of font file issues and details of compilation pipeline in live console. Small, precise and fast. Helps user to accomplish all kinds of font validation, creating, editing and hinting relevant works efficiently. FontCrafter is developed as an alternative to another app - "FontPlus Pro", which developed by the author in the past years, bring user a world-class, industrial-strength font editor for font engineering. A dreamed font editor developed to be completely matched its design principles:

Small, high performance, high maintainable, terse, concise, elegant.


## Features

* Validate and inspect shape and metrics of a glyph.
* Validate an OpenType feature is active or not and glyphs affected by it.
* Validate and inspect arbitrary combination of OpenType features.
* Validate and inspect every table in a TrueType or OpenType font.
* Perfect curves of glyph in pixel grid to match design metrics.
* Fast append missing characters in a font with SVG files.
* Fast append color glyph/emoji in a font with SVG or PNG files.
* Export valid glyph list with their charcodes for glyphs comparison and merging.
* Export glyph shape with precise metrics to SVG or PDF file for reuse and print.
* Export image of emoji or color glyph of an existing font for reuse.
* Subset a big font to a smaller version with code ranges.
* Create color/emoji glyph and normal vector glyph mixed font from scratch.
* Create emoji font from scratch with PNG or SVG files.
* Create Web font (.woff, .woff2, .eot) with an existing font.
* Append, update or delete composite glyphs.
* Append, update or delete character variants and ZWJ.
* Split collection font(.ttc) to multiple TrueType(.ttf) files.
* Append, delete, or update hinting instructs for glyphs.
* Debug TrueType hinting instructs with the embedded high quality debugger.
* Auto-hinting glyphs in an existing font with quality code.
* The TrueType bytecode debugger also supports variation font debugging.
* Validate and inspect hinting result with precise metrics.
